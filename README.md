# Sales Analysis Dashboard (Excel Project)

## Overview

This project is an interactive Sales Analysis Dashboard built using Microsoft Excel.
It provides insights into sales performance, customer behavior, and revenue trends using dynamic charts and slicers.

---

## Key Features

* Total Orders Tracking
* Total Revenue Calculation
* Order-Delivery Time Analysis
* Average Customer Spend
* Revenue breakdown by:

  * Occasion (Diwali, Holi, Birthday, etc.)
  * Product Category (Sweets, Soft Toys, etc.)
  * Time (Hourly trends)
* Top Cities by Orders
* Top 5 Products by Revenue
* Monthly Revenue Trends
* Interactive Filters:

  * Order Date
  * Delivery Date
  * Occasion

---

## Tools and Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers and Timeline Filters
* Data Cleaning and Aggregation

## How to Use

1. Download the Excel file
2. Open in Microsoft Excel (2016 or later recommended)
3. Use slicers to filter data dynamically
4. Explore different charts for insights
